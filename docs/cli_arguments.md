# CLI arguments
CLI arguments are basically a way to add/modify a config of bmake without needing to change config.json.

CLI arguments are made with this syntax:

**bmake  <sup> project path</sup> -*{any_option}***

in which just marks the tag as true, and:

**bmake <sup> project path</sup> -*{any_option}={any_value}***

in which puts the tag as the value after the "=". 
>note that the value is always going to be a string
